Rich text (contenteditable)

Run each step on the first editor, using Text Utilities > Convert to Upper Case, and press Ctrl+Z (Cmd+Z on macOS) before the next step.

  1. Select the bold word "formatted", right-click it, and run the utility. Only that word changes, it stays bold, and the italic text, link and list are untouched. In Firefox the space after the bold word may disappear; typing over the selected word does the same thing there, so that is Firefox's editor rather than the extension.
  2. Select a few words that run from plain text into the italic text, and run the utility. Only the selected words change; everything outside the selection keeps its formatting.
  3. Click inside the editor without selecting anything, right-click, and run the utility. All of the editor's text changes and keeps its line breaks. Formatting is flattened to plain paragraphs, the same as pasting plain text over the whole editor, and Chrome and Edge may add blank lines between paragraphs.
  4. After every step, the counter under the editor shows one more input event.
  5. After every step, Ctrl+Z puts the original text and formatting back.
