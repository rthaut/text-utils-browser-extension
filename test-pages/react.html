React-controlled fields

These fields keep their value in React state, like most modern sites. If React misses a change, it puts the old value back on its next render, or submits the old value.

For each field, select a word, right-click it, and pick Text Utilities > Convert to Upper Case. Then click "Re-render", then "Submit".

Check:

  • "React state" under the field matches the field right after the change.
  • "Re-render" does not put the old text back.
  • "Submitted" shows the new text.
  • Ctrl+Z reverts the change, and "React state" follows it.
