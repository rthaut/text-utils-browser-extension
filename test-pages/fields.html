Inputs and textareas

For each field, click in it without selecting anything, right-click, and pick Text Utilities > Convert to Upper Case. Press Ctrl+Z (Cmd+Z on macOS). Then select one word, right-click it, and run the same utility. Press Ctrl+Z again.

Check:

  • With nothing selected, the whole value changes.
  • With a word selected, only that word changes and it stays selected (with "Only Apply to Selected Text in Editable Content" on, the default).
  • The counter under the field shows one more input event after each change.
  • Ctrl+Z puts the previous text back in one step.
